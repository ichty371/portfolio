# My Portfolio

A one-page portfolio site with an animated topographic map, a custom cursor, project cards, a zoomable map gallery and certificates.

## How to change the content
1. Open `data.js` and change the text (name, email, projects, maps, certificates).
2. Put your pictures in the `images` folder (JPG or PNG).
3. In `data.js`, set `image: "images/your-file.jpg"` for each item.

## How it goes online
The site is hosted on Vercel and linked to this GitHub repository.
Every time you save a change to GitHub, Vercel updates the website automatically (takes about 30 seconds).

No build step is needed: it's plain HTML, CSS and JavaScript.
